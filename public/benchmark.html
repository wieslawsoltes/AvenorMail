Measure retained geometry, complete shaped text lines, images, and independent flex/grid layout on this device. CPU time includes packing, raster preparation, and command submission. Layout time is reported separately. GPU queue time is the wall-clock wait after submission; it includes queue scheduling and is not an isolated GPU execution timestamp. Each item is retained in the scene. Mixed scenes use rectangles, complete shaped multilingual lines, and rounded images. A text line usually occupies one GPU instance; long raster runs use adjacent tiles. The layout workload builds a separate scene tree and culls offscreen display items. Clipping batches preserve scene order. The benchmark includes a five-frame warm-up before the measured frames. Dense overlapping scenes stress fill and submission costs; these results do not predict full application latency or prove one backend is universally faster.
